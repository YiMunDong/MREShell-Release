## MREShell 1.2.0 Preview 1

A native Windows 11 terminal that brings your shells, workspaces, and reusable commands together.

**[Download MREShell.exe](https://github.com/YiMunDong/MREShell-Release/releases/download/v1.2.0-preview.1/MREShell.exe)** · Windows 11 x64 · Freeware

### Requirements

- Windows 11, build 22000 or later, x64.
- **[Microsoft Visual C++ x64 Redistributable](https://aka.ms/vc14/vc_redist.x64.exe)**. Install it if it is not already available on your PC. [Microsoft runtime download information](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist).
- Optional shells such as PowerShell 7, WSL, or Git Bash must be installed separately. SSH uses Windows OpenSSH Client.

### Included features

- Workspaces with terminal tabs, splits, floating panels, and saved layouts.
- A reusable command and script library, parameters, workspace pins, and a command palette.
- Runbooks with readiness checks, shell integration, command journals, and Secret Shield.
- SSH and serial sessions, built-in viewers, three theme families, and five interface languages.
